# Contributing

**English** | [简体中文](CONTRIBUTING.zh-CN.md)

## Maintenance model

The canonical repository for `fastapi-templates-xtn` is:

https://github.com/xtnkking/fastapi-templates-xtn

XTN is the sole maintainer of the canonical repository. Only XTN decides what
is committed, merged, tagged, released, or represented as an official version.

## Issues are welcome

Bug reports, documentation corrections, and feature requests may be submitted
through GitHub Issues. Before opening an issue, search existing issues and
include a minimal reproduction, the expected behavior, the observed behavior,
and relevant environment details when applicable.

Do not put vulnerability details, credentials, personal data, or other
sensitive information in a public issue. Follow `SECURITY.md` instead.

## External pull requests are not accepted

The canonical repository does not accept external pull requests. External pull
requests will be closed without merge. This policy keeps authorship and release
authority for the official project with XTN; it does not limit the permissions
granted by the applicable licenses.

You may download, use, commercially use, fork, modify, and redistribute your
own copy subject to `LICENSE`, `NOTICE`, and `THIRD_PARTY_NOTICES.md`. A fork or
modified distribution is unofficial and must not imply that it is maintained,
approved, sponsored, or endorsed by XTN or by the upstream projects.

When redistributing a modified version, retain the applicable license and
attribution notices and mark modified files as required by the Apache License,
Version 2.0. Preserve the attribution information from `NOTICE` in a form
permitted by that license.

## Issue content intended for inclusion

Unless explicitly marked "Not a Contribution," content intentionally submitted
for inclusion in this project is treated as a Contribution under Section 5 of
the Apache License, Version 2.0. Do not submit material that you do not have the
right to provide under those terms.
